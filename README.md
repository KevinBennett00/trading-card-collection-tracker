# Trading Card Collection Tracker

My project is a trading card collection tracker that will help users keep an organized list of the cards they own. Possible features include adding and removing cards, searching by name, filtering cards by game or set, recording condition and quantity, creating a wishlist, and tracking progress toward completing a set.

I chose this project because I already have trading cards and would like an easier way to keep track of them. There are also several features that can be added as the project develops throughout the semester.
